# Воркшоп по git - создание pull request и запуск CI/CD пайплайна

В рамках любого коммерческого проекта, или проекта, где подразумевается командная работа, разработчики активно пользуются pull request'ами и CI/CD пайплайнами.

Данный кейс знакомит с этими понятиями тех, кто раньше никогда с таким не работал.

Суть задачи:
- Создать новую ветку
- В рамках новой ветки, изменить в файле `script.sh` строчку `echo "TODO"` на `echo "Hello, World"`
- Запушить ветку, создать pull request к ветке `main`
- Принять pull request, посмотреть на результат работы GitHub Action пайплайна. Шаг "Run script" должен вывести "Hello, World"

## Как пользоваться

- Сделайте fork данного репозитория
- Склонируйте локально
- Запушив ветку, создайте Pull Request к ветке main своего форка на GitHub
